## Introduction

SoftMicro-DOG is designed to mimic the feel of MS-DOS while incorporating humorous elements and modern coding practices. This project is perfect for anyone who enjoys retro computing or wants to learn more about assembly language and system programming.

## Features

- **Parody Interface**: Enjoy a playful take on the classic MS-DOS interface.
- **Assembly Language**: Written in assembly language for a deeper understanding of system-level programming.
- **Open Source**: Released under GPL-3.0, allowing anyone to modify and distribute the software.
- **Community Driven**: Contributions are welcome, and community input shapes the project's direction.

## Installation

To get started with SoftMicro-DOG, follow these steps:

1. **Clone the Repository**: Use the following command to clone the repository to your local machine.

   ```bash
   git clone https://github.com/Teopeo4099/SoftMicro_SM-DOG.git
   ```

2. **Build the Project**: Navigate to the project directory and build the project using the provided Makefile.

   ```bash
   cd SoftMicro_SM-DOG
   make
   ```

3. **Run the Software**: After building, execute the binary file to start using SoftMicro-DOG.

   ```bash
   ./sm-dog
   ```

## Usage

Once you have installed SoftMicro-DOG, you can start using it immediately. The interface resembles MS-DOS, allowing you to enter commands in a familiar format. Here are a few commands to get you started:

- **HELP**: Displays a list of available commands.
- **ECHO**: Outputs text to the screen.
- **DIR**: Lists files in the current directory.
- **EXIT**: Closes the program.

Feel free to experiment with other commands and see what surprises await!
